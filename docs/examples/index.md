# Examples status

Executable examples are deferred until the corresponding layers pass structural,
distributional, gradient, and lowering tests. Planned examples are:

1. An exact high-level reconstruction of TorX's stochastic convolution notebook.
2. A two-dimensional shared stencil with automatic conflict scheduling.
3. An energy-native binary convolution checked against a small exact conditional.
4. Explicit PCNOT, OR, majority, count, and sample pooling comparisons.
5. A small bars-and-stripes model before any larger image benchmark.

Examples must publish expected semantics and evidence; they must not serve as substitutes
for tests.
